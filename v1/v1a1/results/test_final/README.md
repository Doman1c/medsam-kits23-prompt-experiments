# V1a.1 Frozen Test Results

This directory contains compact, version-controlled summaries from the one-time frozen V1a.1 test evaluation.

- `error_analysis/`: descriptive failure categories, side-presence status, and case-level concentration.
- `oracle_presence_decomposition/`: A/B/C decomposition of presence-decision and automatic-box contributions to the oracle gap.

The full per-slice predictions and MedSAM masks are intentionally not tracked in Git. See `../../docs/FROZEN_TEST_EVALUATION_AND_ERROR_ANALYSIS.md` for methods, results, interpretation, and research safeguards.
